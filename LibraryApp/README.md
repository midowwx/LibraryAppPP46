# LibraryApp

## Описание
Консольное приложение на C#, имитирующее работу небольшой библиотеки. Проект создан в рамках учебного задания для демонстрации процессов отладки, статического анализа кода и документирования результатов тестирования.


## Архитектура
Приложение состоит из двух основных классов:

* Book - модель книги.
   * Свойства: Id (int), Title (string), Author (string), IsAvailable (bool, по умолчанию true).
* Library - класс управления каталогом.
   * Поля: приватный readonly список книг.
   * Методы:
      * AddBook(Book book) - добавляет книгу в каталог с проверкой на null и пустые поля.
      * BorrowBook(int id) - выдает книгу, устанавливая IsAvailable = false.
      * ReturnBook(int id) - принимает книгу обратно, устанавливая IsAvailable = true.
      * FindBook(int id) - возвращает экземпляр книги по идентификатору.

## Функциональность
Приложение позволяет:

1. Добавлять книги в каталог.
2. Выдавать книги пользователям (блокируя их для других читателей).
3. Возвращать книги в библиотеку.
4. Искать книги по их ID.

## Подготовка и запуск
1. Убедитесь, что на вашем компьютере установлена среда Visual Studio 2022 или новее с поддержкой .NET 8.
2. Клонируйте репозиторий или скопируйте исходный код в локальную папку.
3. Откройте файл решения LibraryApp.sln в Visual Studio.
4. Нажмите Ctrl + F5 (Запуск без отладки) или F5 (Запуск с отладкой).
